The goal of this project was to build a modern web application that fetches and displays TV show data from an external API. I wanted to improve my skills in JavaScript, especially working with APIs, handling asynchronous data using fetch, and dynamically updating the DOM.

The main part of the app is the fetch function, where I request data from the TVMaze API.

This project helped me significantly improve my JavaScript skills, especially working with APIs and DOM manipulation.

One thing I learned was how to properly structure asynchronous code using async/await, which made my code cleaner and easier to understand.
